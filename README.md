# ReBlueOutlet · Catálogo

Versión preparada para GitHub Pages.

## Publicar
1. Sube todo el contenido de esta carpeta a la raíz del repositorio.
2. En GitHub: Settings → Pages.
3. Selecciona `Deploy from a branch`.
4. Rama `main` y carpeta `/ (root)`.
5. Guarda y espera a que GitHub Pages publique el sitio.

## Estructura
- `index.html`: página del catálogo.
- `catalogo-productos.json`: datos públicos del catálogo.
- `.nojekyll`: evita procesamiento innecesario de GitHub Pages.

El JSON público contiene únicamente nombre, referencia, stock, precio de venta y foto. No incluye precio de compra, beneficio ni comentarios internos.
